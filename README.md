How the Work Was Done

The project follows a basic data analysis workflow:

1. Data Collection

The dataset was prepared and imported into Microsoft Excel for analysis.

2. Data Cleaning

The data was reviewed and organized to identify possible errors, missing values, duplicates, and inconsistencies.

3. Data Analysis

Excel functions, Pivot Tables, and other analytical techniques were used to explore the dataset and identify useful patterns and insights.

4. Data Visualization

Charts and visual elements were created to make the results easier to understand.

5. Dashboard Development

The analyzed information was organized into an interactive dashboard containing charts, summaries, and KPIs.

6. Insights

The dashboard was used to communicate the main findings from the dataset in a simple and understandable way.
