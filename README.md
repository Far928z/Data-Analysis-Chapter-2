# Data-Analysis-Chapter-2
My Sales — SQL Data Analysis Project

📌 Project Overview

My Sales is a SQL-based sales data analysis project created to practice and demonstrate how sales data can be stored, managed, queried, and analyzed using MySQL.

The project uses sales information such as products, regions, quantities, unit prices, and total sales. SQL queries are used to transform the raw sales records into useful business insights.

📊 Data Structure

The My Sales table contains the following main columns:

Column	Description
Sale_ID	Unique identification number for each sale
Sale_Date	Date of the transaction
Product	Product sold
Region	Location where the sale occurred
Quantity	Number of units sold
Unit_Price	Price of one unit
Total_Sales	Total value of the transaction

The Total_Sales value is calculated based on:

Quantity × Unit Price

🔄 How the Project Is Managed

The project follows a simple data-management and analysis workflow:

1. Database Creation

A dedicated database is created to store the sales information.

2. Table Creation

A table named My Sales is created with appropriate data types for dates, products, regions, quantities, prices, and sales values.

3. Data Entry

Sales records are inserted into the database using SQL INSERT INTO statements.

4. Data Retrieval

SELECT statements are used to retrieve and inspect the stored data.

5. Data Analysis

SQL aggregation functions such as:

* SUM()
* AVG()
* COUNT()
* MAX()
* MIN()

are used to analyze the sales data.

6. Grouping and Comparison

GROUP BY and ORDER BY are used to compare sales across different products and regions.

7. Filtering Results

WHERE and HAVING are used to filter records and identify specific results.
